Adding a product to Cart must NOT reduce stock.

Stock should reduce ONLY after the Order is successfully placed.

If the Order is cancelled before delivery,

the stock should automatically be restored.

Explain this business logic before implementation.

3. PRODUCT DELETION RULES

Products should never be permanently deleted if they are already used
in Orders.

Instead,

mark the Product as

Inactive

or

Discontinued.

Explain why this is preferred in real-world applications.

A Category cannot be deleted if Products exist inside it.

Admin should first

Move Products

OR

Deactivate Products

before deleting the Category.

Generate proper validation and user-friendly error messages.

========================================================================
5. COUPON BUSINESS RULES

Implement the following rules:

Coupon must not be expired.

Inactive Coupon cannot be used.

Coupon Code must be unique.

One customer should not be able to use the same coupon repeatedly
unless explicitly allowed.

If a Coupon is expired,

display it as Expired / Disabled.

Do not remove historical coupon records.

========================================================================
6. ADDRESS MANAGEMENT RULES

A Customer can

Add Address

Edit Address

Delete Address

Set Default Address

Only ONE Default Address should exist for one Customer.

If another Address becomes Default,

the previous Default Address should automatically become non-default.

Do not allow deletion of the only Default Address unless another
address is selected as Default.

========================================================================
7. WISHLIST RULES

A Customer cannot add the same Product multiple times.

If the Product already exists in Wishlist,

display an appropriate message.

Use UserId + ProductId as the uniqueness check.

========================================================================
8. CART RULES

A Customer cannot have duplicate entries of the same Product in Cart.

If the Product already exists,

increase the Quantity instead of inserting another row.

Quantity cannot become less than one.

Generate Increase Quantity and Decrease Quantity functionality.

9. PRODUCT RATING RULES

Only Customers who have successfully purchased a Product should be
allowed to rate it.

Do not allow ratings from users who never purchased the Product.

The Product AverageRating should automatically update whenever a new
rating is submitted.

Explain the calculation logic.

Use the existing ImagePath field.

Each Product should have only ONE image.

Validate

Allowed Extensions

Maximum File Size

Invalid File Types

If image is missing,

display a Default Product Image.
